# 원본 키캡 기반 OpenSCAD 각인

`open-keycap.cmd`를 실행해 OpenSCAD를 열고 Customizer(사용자 정의 창)에서 값을 바꿉니다. 이 실행 파일은 포함된 폰트 폴더를 OpenSCAD에 연결합니다. 먼저 Customizer 위쪽의 `Automatic Preview` 체크를 끄고, 값을 바꾼 다음 F5를 눌러 미리보기를 갱신하세요. OpenSCAD 2021은 SCAD 파일이나 실행 옵션으로 이 체크를 자동 해제할 수 없습니다. `blank-4.stl`과 `blank-5.stl`은 같은 폴더에 두세요. 제공받은 3MF의 두 메시를 좌표 변경 없이 추출했습니다. 빌드 플레이트 배치용 128 mm 이동은 적용하지 않았습니다.

- legend_text: 기본 문자열은 `최강한글`입니다. font_name 목록에서 Noto Sans KR, 빙그레 4종, 배달의민족 11종과 맑은 고딕을 선택할 수 있습니다. Noto Sans KR은 Thin부터 Black까지 9개 굵기를 포함합니다. 다른 폰트에서 지원하지 않는 font_style을 선택하면 해당 폰트의 기본 또는 가장 가까운 굵기로 표시됩니다.
- key_count: 한 번에 만들 키캡 수(최대 30개).
- columns: 한 줄에 놓을 키캡 수.
- key_spacing: 키캡 중심 간격. 기본 21 mm.
- legend_text에는 `최강한글`처럼 키 순서대로 한 글자씩 입력합니다. key_count가 문자열보다 크면 남는 키는 민무늬로 생성됩니다. 여러 글자로 된 `Esc`, `Tab` 같은 레전드를 키별로 지정하는 기능은 이 버전에는 없습니다.
- size: 글꼴 크기(mm). 실제 글자 외곽 높이와는 다를 수 있습니다.
- depth: Z 방향 각인 깊이/양각 높이. 곡면 법선 방향의 일정한 깊이는 아닙니다.
- x, y, rotation, mirror_horizontal: 첫 글자의 위치, 회전, 반전.
- svg_file: 비워두면 글자 사용. SVG 경로를 입력하면 첫 글자를 대체합니다. SVG 글자는 경로로 변환하세요.
- double_legend: 두 번째 글자를 추가합니다.
- style: inlay(다색용 매립), engraved(음각), raised(양각).
- part: preview(색상 미리보기), body(몸체 출력), legend(각인 부품 출력), blank(원본).

다색 출력은 style=inlay에서 body와 legend를 각각 F6 렌더 후 STL로 내보내세요. 기본 ‘최’의 출력 예제 body.stl, legend.stl도 포함되어 있습니다. 두 파일을 슬라이서에 함께 불러와 하나의 객체에 속한 부품으로 묶고 각 부품의 필라멘트를 지정하세요. 각 파일을 따로 자동 정렬하거나 바닥으로 내리면 정렬이 어긋납니다. STL에는 색상 정보가 없습니다.

원본 외형과 체결 구조를 사용하는 첫 버전입니다. 체결 공차 조절, homing bump, 투광 관통, A–Z 개별 일괄 출력, 색상 지정 3MF 자동 생성은 아직 구현하지 않았습니다. 모델 크기 변경 기능도 없습니다.

큰 글자나 과도한 위치 이동은 가장자리까지 잘릴 수 있습니다. 각인 연산은 Z=8 mm 이상에만 적용됩니다. 깊은 각인, 넓은 SVG, 다른 글꼴을 사용할 때는 슬라이서 단면에서 상판 두께와 가는 획을 확인하세요. 실물 출력 및 스위치 결합은 검증하지 않았습니다.

검증: OpenSCAD 2021.01에서 기본 설정의 몸체와 각인 STL 렌더 성공, 두 결과 Simple=yes. Noto Sans KR 한글 미리보기를 확인했습니다. 미리보기에서 강제 CGAL render 호출을 제거해 4개 키 기준 약 40초에서 약 2초로 줄였습니다. 빠른 미리보기에서 면 깜빡임을 막기 위해 글자만 0.03 mm 위에 표시하며, 몸체·글자 STL의 실제 위치와 치수에는 영향을 주지 않습니다. 나머지 옵션 조합은 전부 검증한 것은 아닙니다.

폰트 파일의 사용·배포 조건은 각 폰트 제공자의 라이선스를 따르세요. 이 묶음은 사용자가 제공한 파일로 만든 로컬 작업용 사본입니다.

한글이 네모나 물음표로 나오면 작업을 저장하고 열려 있는 OpenSCAD 창을 모두 종료하세요. 작업 관리자에도 `openscad.exe`가 남아 있지 않은 상태에서 `open-keycap.cmd`로 다시 엽니다. 실행기는 기존 OpenSCAD 프로세스가 있으면 안내 메시지를 표시하고 중단합니다. `.scad` 파일을 직접 더블클릭하거나, 이미 실행 중인 OpenSCAD에서 열면 포함 폰트 경로가 전달되지 않습니다. 값을 바꾼 뒤 F5로 미리보기를 갱신합니다.
